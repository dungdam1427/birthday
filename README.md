# Birthday Cake Shop 🎂

Trang thiệp chúc mừng sinh nhật + game tiệm bánh 2D (một file HTML, không cần cài đặt).

## Chạy thử trên máy
Mở `index.html` bằng trình duyệt.

## Đưa lên web (GitHub Pages)
Settings → Pages → Source: Deploy from a branch → Branch: main, thư mục / (root) → Save.
Link: https://TEN-GITHUB.github.io/TEN-REPO/

## Lưu tiến trình
Dùng localStorage của trình duyệt (khóa `bcs_save_v1` và `bcs_order_v1`).
